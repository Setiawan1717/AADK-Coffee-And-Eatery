# AADK Coffee & Eatery, Jalan Bandung Malang

Website satu halaman untuk Ada Apa Dengan Kopi (AADK) cabang Jl. Bandung No. 28, Malang.

- Buka setiap hari 07.00–24.00
- Menu, event, promo, reservasi lewat WhatsApp, lokasi, dan jam buka
- HTML, CSS, dan JavaScript biasa dalam satu file, tanpa framework

## Mengubah isi

Semua data (menu, harga, event, promo, galeri, FAQ, kontak) ada di bagian `DATA WEBSITE` di bagian bawah `index.html`.
Data bertanda `(CONTOH)` dan komentar `GANTI` masih sementara dan perlu diganti dengan data asli dari kafe.

## Hosting

Aktifkan GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
